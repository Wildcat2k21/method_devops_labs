# Шпаргалка: команды Linux

| Команда    | Назначение                                   | Пример                                   |
|------------|----------------------------------------------|------------------------------------------|
| `pwd`      | показать текущий каталог                     | `pwd`                                    |
| `ls`       | список файлов                                | `ls -la ~/devops`                        |
| `cd`       | сменить каталог                              | `cd ~/devops/lab5`                       |
| `mkdir`    | создать каталог                              | `mkdir -p ~/devops/lab5/git`             |
| `touch`    | создать пустой файл                          | `touch notes.txt`                        |
| `echo`     | вывести строку / записать в файл             | `echo "текст" >> commands.txt`           |
| `cat`      | показать содержимое файла                    | `cat commands.txt`                       |
| `chmod`    | изменить права доступа                       | `chmod +x info.sh`                       |
| `find`     | найти файлы                                  | `find ~/devops -name "*.txt"`            |
| `grep`     | найти строки по шаблону                      | `grep -n "Linux" commands.txt`           |
| `whoami`   | имя пользователя                             | `whoami`                                 |
| `hostname` | имя хоста                                    | `hostname`                               |
| `df`       | свободное место на дисках                    | `df -h /`                                |

## Git

| Команда                         | Назначение                              |
|---------------------------------|-----------------------------------------|
| `git init`                      | создать репозиторий                     |
| `git status`                    | состояние рабочей копии и индекса       |
| `git add <файл>`                | добавить изменения в индекс             |
| `git commit -m "<сообщение>"`   | зафиксировать изменения                 |
| `git switch -c <ветка>`         | создать ветку и перейти в неё           |
| `git merge <ветка>`             | слить ветку в текущую                   |
| `git log --oneline --graph`     | история коммитов в виде графа           |
| `git remote add origin <url>`   | привязать удалённый репозиторий         |
| `git push -u origin main`       | отправить ветку на сервер               |
